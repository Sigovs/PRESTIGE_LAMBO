# Official Lamborghini images: manifest

**Retrieved:** 30 Sep 2026, with Playwright (Chrome, US IP) and curl.

**Why lamborghini.com and not the media centre.** The media centre was tried first: `https://media.lamborghini.com/english` and the Revuelto SV release URL. Both return **HTTP 302 to https://www.lamborghini.com/en-en** (checked with curl and in Playwright), so the press library is not publicly reachable today. Every image below is therefore an official Automobili Lamborghini asset from the lamborghini.com DAM (`/sites/it-en/files/DAM/…`), taken from the model page named in each row.

**Captions and credit.** The site publishes no caption or photographer credit. The alt text is reproduced exactly as given. Rights: © Automobili Lamborghini S.p.A. (lamborghini.com footer). Dealer reuse must be confirmed with Lamborghini Americas.

**Model identification.** Every image was checked by eye, not taken from its file name:
- SE Performante vs SE: the Performante has a carbon bonnet with vents, carbon lower trims and a "Performante" sill script; the SE has a plain body-colour bonnet.
- Revuelto vs Revuelto SV: the SV has a fixed rear wing and an "SV" livery; the Revuelto has neither.
- Temerario: hexagonal DRLs.
